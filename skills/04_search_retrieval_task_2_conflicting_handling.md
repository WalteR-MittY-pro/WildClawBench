# Conflicting Information Handling between Local Data and Web

## Core Challenge

The core cognitive challenge is **conflicting source reconciliation under temporal uncertainty**. The agent must recognize that pre-existing reference materials may contain outdated legal provisions, proactively verify their current validity against authoritative online sources, and resolve contradictions between local and external information by determining which source reflects the operative law. This tests the agent's ability to question the reliability of provided context, independently seek authoritative updates, and synthesize conflicting information rather than simply retrieving and applying the first relevant rule it encounters.
