# Crawl SCP-001 to SCP-050 with Text, Images, and Metadata

## Core Challenge

The core cognitive challenge is **sustained workflow orchestration across repeated operations with subtle structural variations**. Agents typically struggle to maintain consistent extraction logic across 50 individual web pages where each has idiosyncratic HTML structure (SCP-001 has multiple proposals, some entries use different collapsible block implementations, class labeling varies). The strategic difficulty lies in balancing exploration (understanding page-specific anomalies) with exploitation (applying a general scraping pattern), while maintaining state awareness to ensure all 50 items are correctly processed, classified, and summarized without dropping edge cases or misidentifying decorative images as content.
