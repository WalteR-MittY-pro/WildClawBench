# Academic Homepage Style Transfer

## Core Challenge

The core cognitive challenge is **multimodal information synthesis with constraint-based filtering**: the agent must extract structured information from screenshots (template style and author details), apply multiple temporal and publication-type filters (first-author ICCV/CVPR 2025 papers, pre-October news), and integrate these constraints into a cohesive website adaptation. Agents typically struggle with accurately interpreting visual layouts and systematically cross-referencing extracted data against multiple filtering criteria without omitting or misapplying constraints.
