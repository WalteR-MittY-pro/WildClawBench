# Confirm the location of an artwork.

## Core Challenge

The core cognitive challenge is **temporal grounding in information retrieval**: the agent must not only identify the artwork through visual analysis and search, but critically must verify its *current* physical location at a specific point in time (mid-July 2025), which requires understanding that artworks move between institutions for exhibitions, loans, and tours. Agents typically struggle with distinguishing between an artwork's permanent collection home versus its temporary location, and fail to recognize that location information is time-sensitive and requires verification against the specified date rather than accepting static historical facts.
