# Search Efficiency Test

## Core Challenge

The core cognitive challenge is **strategic search query formulation under strict resource constraints**. Agents must decompose a multi-part question into an optimal sequence of searches that balance specificity (to get precise answers quickly) with breadth (to handle uncertainty about where information lives), all while operating under a hard limit that penalizes exploratory or redundant queries. The difficulty lies in predicting which search strategies will yield both pieces of required information within the budget, requiring forward-planning about information sources (official docs vs. GitHub vs. release notes) rather than iterative refinement.

1. **Understand all requirements before acting**: Prevents missing critical constraints → Jumping to implementation without full context
