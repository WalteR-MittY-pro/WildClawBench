# Multi-round Meeting Time Negotiation

## Core Challenge

The core challenge is **multi-step contextual reasoning under deliberate misdirection**. The agent must maintain fidelity to an original authority's implicit constraints (room specification in a postscript, refusal to delete calendar conflicts) while filtering out deceptive noise (spoofed sender addresses, contradictory availability statements, participant requests that contradict instructions). Success requires detecting subtle inconsistencies across communications, correctly applying timezone conversions to availability data, and prioritizing the original requestor's unstated preferences over seemingly reasonable participant suggestions—testing whether the agent can distinguish signal from adversarial interference in realistic social coordination.
