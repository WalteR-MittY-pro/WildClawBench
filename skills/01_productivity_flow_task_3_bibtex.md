# Recover Official arXiv Titles and BibTeX from Local PDFs

## Core Challenge

The core cognitive challenge is **multi-source information reconciliation under uncertainty**: the agent must bridge unreliable local artifacts (messy filenames, potentially corrupted PDFs) with authoritative external sources (arXiv metadata) by extracting identifying information from damaged documents, then systematically cross-reference and validate across multiple information channels (PDF metadata, content extraction, web searches, arXiv APIs) to establish ground truth. This tests the agent's ability to handle ambiguity and incomplete evidence, prioritize information sources by reliability, and maintain consistency across interdependent outputs when no single source provides complete or trustworthy information.
