# Link-a-Pix Color — Solve Puzzle and Recognize Filled Pattern

## Core Challenge

The core cognitive challenge lies in **constraint satisfaction with spatial reasoning under ambiguity**: the agent must decompose a visual puzzle into structured data (number positions, values, and colors), then solve a complex path-finding problem where multiple interdependent constraints (path length matching values, no crossings, complete grid coverage) must be satisfied simultaneously. Agents typically struggle with the combinatorial explosion of possible path configurations and the need to backtrack when local decisions create global impossibilities, requiring strategic lookahead rather than greedy local optimization. The additional challenge of multimodal integration—accurately extracting numerical and color information from an image then mapping the abstract solution back to visual output—tests the agent's ability to bridge perception, logical reasoning, and generation within a tight time constraint.
