# Extract Biography Sections from Wikipedia

## Core Challenge

The core cognitive challenge is **multi-step information retrieval with entity resolution across linked resources**. The agent must extract person names from unstructured biographical text, disambiguate those names from titles and aliases to find their canonical forms, then navigate to separate Wikipedia pages to verify the existence of specific sections and extract content—all while maintaining consistency in naming conventions and filtering criteria across multiple web sources. This tests the agent's ability to chain dependent lookups where each step's success depends on correctly interpreting context from the previous step, particularly distinguishing between a person's various appellations to match them to their actual Wikipedia article.
