# Resume to Academic Homepage

## Core Challenge

The core challenge is **multi-source information synthesis with selective filtering under explicit constraints**. The agent must extract structured information from a PDF resume, cross-reference it with visual style guidelines from a screenshot, apply multiple exclusion criteria to filter publications (author position, review status, venue type) and temporal news items, then orchestrate these filtered elements into a cohesive output while managing cross-modal understanding (text extraction, visual template interpretation) and respecting strict inclusion/exclusion rules that require semantic understanding of academic publishing conventions rather than simple pattern matching.
