# Design a Product Poster for a Leather Briefcase

## Core Challenge

The core cognitive challenge is **inferential feature extraction and marketing translation** — the agent must visually analyze an unlabeled product image to independently identify which physical attributes constitute marketable "features" (texture suggesting premium material, stitching indicating craftsmanship, compartments implying functionality), then synthesize these observations into persuasive marketing language and hierarchical visual presentation that aligns with brand positioning. This requires bridging perceptual analysis with cultural/commercial knowledge about what makes products desirable, a form of subjective interpretation that agents struggle with because "standout features" aren't objectively encoded in pixels but emerge from understanding consumer values and design intent.
