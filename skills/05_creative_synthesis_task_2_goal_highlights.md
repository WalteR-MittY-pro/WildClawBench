# Goal Highlights Compilation

## Core Challenge

The core cognitive challenge is **temporal event detection and contextual boundary identification in continuous multimodal data**. Agents must parse extended video content to identify sparse, specific events (goals by a particular player), then make nuanced judgment calls about where meaningful action sequences begin and end—distinguishing between the buildup to a goal, the goal itself, and post-goal celebration. This requires understanding both visual semantics (recognizing players, ball movement, scoring moments) and temporal narrative structure (what constitutes a "complete attacking sequence"), which demands integrating information across multiple modalities and time scales rather than applying rule-based pattern matching.
