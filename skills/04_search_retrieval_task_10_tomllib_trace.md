# Search Traceability Test

## Core Challenge

The core cognitive challenge is **strategic search optimization under resource constraints**. Agents must decompose a multi-part question into an efficient search sequence that balances specificity (to find precise technical details like PR numbers) with breadth (to establish foundational facts like version numbers), while continuously evaluating whether remaining searches are sufficient to complete both requirements or whether early termination is necessary. The difficulty lies in planning a search strategy that maximizes information gain per query rather than executing searches reactively, and knowing when partial success should trigger abandonment versus pivoting to alternative search formulations.

## Solution Strategy


1. **Understand all requirements before acting**: Prevents missing critical constraints → Jumping to implementation without full context




## Common Failure Patterns


- **Incomplete requirement analysis**: Acting on partial information → Missing critical constraints


## Self-Check Questions


- [ ] Did I fully understand all requirements and constraints before starting?

- [ ] Have I validated my approach against ALL stated criteria?

- [ ] Did I use all available search constraints effectively?

- [ ] Did I verify the output format matches expectations?

- [ ] Have I checked for edge cases and error conditions?

- [ ] Did I test the complete workflow end-to-end?

- [ ] Have I confirmed all required information was gathered?

- [ ] Did I avoid making assumptions without verification?
