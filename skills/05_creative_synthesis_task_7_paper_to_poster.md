# Academic Paper to Conference Poster

## Core Challenge

The core challenge is **synthesizing a coherent academic narrative from complex technical content and translating it into a visually coherent design artifact**. Agents typically struggle with the multi-stage creative pipeline: extracting salient information from dense research papers, determining what visual elements best communicate key contributions, and orchestrating layout decisions that balance information hierarchy with aesthetic coherence—all while maintaining academic conventions without explicit design specifications. The task requires bridging abstract understanding (what matters scientifically) with concrete visual reasoning (how to represent it effectively), demanding both analytical distillation and compositional judgment rather than following templated rules.
