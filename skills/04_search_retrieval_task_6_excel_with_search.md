# Integrated Search of Local and Online Information

## Core Challenge

The core cognitive challenge is **multi-step information integration across heterogeneous sources under constrained conditions**. Agents must first apply multiple simultaneous filters to tabular data to identify a specific entity, then synthesize domain knowledge from web searches with numerical data from multiple files to perform a comparative calculation that requires understanding the implicit definition of a categorical threshold (what constitutes a "primary airport"). The difficulty lies in maintaining goal coherence across context switches between structured data extraction, external knowledge retrieval, and cross-source reasoning rather than in any single operation.
