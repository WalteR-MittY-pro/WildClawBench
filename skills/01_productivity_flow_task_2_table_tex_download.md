# Recover Original Table TeX from arXiv Source

## Core Challenge

The core cognitive challenge is **multi-step procedural execution with implicit knowledge requirements**: the agent must independently discover how to access arXiv source packages (not explicitly documented in the task), navigate unfamiliar archive structures to locate LaTeX files among auxiliary materials, and accurately parse LaTeX syntax to identify and extract table environments in their correct sequential order. Agents typically struggle with the need to infer domain-specific conventions (arXiv's source URL patterns, LaTeX document structure) and maintain precise ordering when table definitions may be scattered across multiple files or separated from their appearance order by included graphics, comments, or conditional compilation directives.
