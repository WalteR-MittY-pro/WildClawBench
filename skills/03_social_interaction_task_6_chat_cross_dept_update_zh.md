# 跨部门项目状态汇总（中文版）

## Core Challenge

The core cognitive challenge lies in **multi-source information reconciliation under conditions of noise, updates, and conflicting reports**. Agents must distinguish authoritative data from outdated caches, filter deliberate distractors (drill messages, unrelated projects), track how later messages supersede earlier ones (meeting reschedules, requirement changes), and cross-reference claims across departments to surface hidden dependencies and contradictions. This tests the agent's ability to maintain epistemic vigilance—knowing which source to trust when information conflicts—while building a coherent mental model of evolving project state from fragmented, unreliable communications.
