# Connect the Dots (Medium) — Only Image

## Core Challenge

The core cognitive challenge is **multimodal perception and spatial reasoning**: the agent must extract structured numerical data (point labels and coordinates) from visual input, then translate that spatial understanding into executable code that correctly sequences and connects points in coordinate space. Agents typically struggle with the reliability of visual-to-structured-data extraction—accurately detecting all numbered points, correctly reading small or ambiguous labels via OCR, and mapping visual positions to precise pixel coordinates without losing or misidentifying any elements in the chain.
