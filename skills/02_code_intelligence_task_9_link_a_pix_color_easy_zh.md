# Link-a-Pix Color (Easy) — Solve Puzzle and Recognize Filled Pattern

## Core Challenge

The core cognitive challenge is **spatial constraint satisfaction under global interdependency**: the agent must recognize that each local path-finding decision constrains the solution space for all remaining pairs, requiring strategic ordering and backtracking when paths block each other. Agents typically struggle with the combinatorial explosion of valid path configurations and fail to develop heuristics for which number pairs to connect first, often getting trapped in local solutions where the final pairs cannot be legally connected. The difficulty lies not in implementing pathfinding algorithms, but in understanding that this is a tightly-coupled global optimization problem where greedy local decisions lead to unsolvable board states.
