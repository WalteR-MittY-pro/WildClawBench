# Connect the Dots (Hard) — Recognize Pattern After Connecting

## Core Challenge

The core cognitive challenge is **spatial pattern recognition under incomplete information**—the agent must extract discrete numbered points organized into color-coded groups from a visual image, then synthesize these fragmented numerical sequences into coherent linear paths that reveal a hidden pictorial representation. Agents typically struggle with the multi-modal reasoning gap between low-level perception (accurately localizing and grouping 162 numbered points by color) and high-level semantic interpretation (recognizing what emergent shape the connected lines form), especially when working under time pressure that demands efficient heuristics over exhaustive analysis. The strategic difficulty lies in deciding how much effort to invest in perfect point detection versus accepting noisy data and relying on the final visual gestalt to compensate for localization errors.
