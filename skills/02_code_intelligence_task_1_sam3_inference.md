# SAM3 Inference Code Implementation

## Core Challenge

The core cognitive challenge is **reverse-engineering an API from undocumented source code**. The agent must navigate an unfamiliar codebase without external documentation, trace through implementation details to infer the correct usage patterns, parameter formats, and data transformations (like coordinate normalization schemes), then synthesize this understanding into working code. This tests the ability to build a mental model of software architecture through code reading alone, distinguishing between internal implementation details and intended public interfaces—a skill that requires understanding implicit conventions, recognizing design patterns, and making inferences about developer intent from implementation clues rather than explicit specifications.

## Solution Strategy


1. **Understand all requirements before acting**: Prevents missing critical constraints → Jumping to implementation without full context




## Common Failure Patterns


- **Incomplete requirement analysis**: Acting on partial information → Missing critical constraints
