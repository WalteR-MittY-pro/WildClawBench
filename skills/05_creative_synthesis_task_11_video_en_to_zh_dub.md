# Video English Speech Extraction, Translation & Chinese Dubbing

## Core Challenge

The core cognitive challenge is **multi-stage workflow orchestration with implicit dependencies** — the agent must decompose an underspecified end goal into a coherent sequence of heterogeneous operations (audio extraction, speech recognition, translation, text-to-speech synthesis, audio-video remuxing), autonomously select appropriate tools and models for each stage, and manage intermediate artifacts while ensuring compatibility between disparate processing pipelines that typically have format, timing, and encoding constraints.

## Solution Strategy


1. **Understand all requirements before acting**: Prevents missing critical constraints → Jumping to implementation without full context




## Common Failure Patterns


- **Incomplete requirement analysis**: Acting on partial information → Missing critical constraints
